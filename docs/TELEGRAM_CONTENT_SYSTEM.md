# Инструкция: Публикация и генерация контента для Telegram-канала «Добрый дом Тюмень»

Данная система позволяет осуществлять поиск инфоповодов, генерировать структурированные и вовлекающие посты для Telegram и публиковать их напрямую в канал или чат через Telegram MCP.

---

## 1. Конфигурация бренда
- **Профиль тенанта:** `shared/tenant-config.json`
- **Контент-бриф:** `memory/brief/site-brief.md`
- **Голос и тональность (Tone of Voice):** `shared/SOUL.md`
- **Шаблоны рубрик и структура постов:** `shared/telegram-post-templates.json`

---

## 2. Рубрики контента
1. **Афиша и события Тюмени (`afisha`)** — мероприятия, выставки, горячие источники, фестивали + подборка квартир рядом.
2. **Гид по районам и ЖК (`district_guide`)** — ЖК Новин, Европейский Берег, Видный, Звёздный, Центр, Набережная, Аквапарк «ЛетоЛето».
3. **Сервис, забота и лайфхаки (`service_lifehack`)** — бесконтактное заселение 24/7 за 5 минут, идеальная чистота, отчетные документы командировочным с QR-кодом.
4. **Акции и скидки (`special_offers`)** — скидки 10% на раннее бронирование (от 20 дней) и длительное проживание (от 10 ночей).
5. **Гид по Тюмени (`city_guide`)** — термальные источники, гастрономия сибирской кухни, улица Дзержинского.

---

## 3. Как запустить генерацию поста

### Быстрый запуск через скрипт:
```bash
# Генерация поста по афише
python3 scripts/generate_telegram_post.py --category afisha --topic "Афиша выходных в Тюмени: куда сходить"

# Генерация поста по ЖК и районам
python3 scripts/generate_telegram_post.py --category district_guide --topic "Квартиры в ЖК Новин и Европейский"

# Генерация поста про сервис и бесконтактное заселение
python3 scripts/generate_telegram_post.py --category service_lifehack

# Генерация поста про скидки и тарифы
python3 scripts/generate_telegram_post.py --category special_offers
```

Сгенерированный пост сохраняется в формате JSON и Markdown в папку `memory/telegram_posts/`.

---

## 4. Публикация в Telegram через MCP
Сгенерированный пост содержит HTML-разметку и инлайн-кнопки со ссылкой на официальный сайт `https://добрый-дом-тюмень.рф` и контакт администратора. 

Агент может автоматически отправить пост в канал с помощью MCP инструмента `mcp-kv:telegram_send_message` или `mcp-kv:telegram_send_photo`.
